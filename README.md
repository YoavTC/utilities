# Utilities

## Simple BAT Scripts

### util.bat

Lists all of the files in the utility directory

### shrink_video.bat

Attempts to shrink a video file's size to the given size (KB)
<br> requires [FFmpeg](https://ffmpeg.org/)

### download_audio.bat

Attempts to download the audio file of a YouTube video
<br> requires [yt-dlp](https://github.com/yt-dlp/yt-dlp)

### create_datapack.bat

Creates a Minecraft datapack folder tree with a given namespace

## [Raycast](https://www.raycast.com/) Scripts

### hash-file.py

Opens a simple GUI application that generates the SHA-256 hash from a file

### python-server.py

Opens a simple GUI application that lets you open a local python server at a selected location, with the ability to specify the port
